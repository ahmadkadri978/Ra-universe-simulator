## Practical limits

- Educational model; no prediction or spiritual measurement.
- Session state resets on reload.
- Recent geometry is capped at 8 compact / 14 desktop events; the full appropriate-lens history stays in text.
- Mobile bloom is disabled. Physical low-end devices have not been benchmarked.
- The Three.js-based bundle is approximately 308 kB gzipped, excluding the preserved legacy HTML. Vite emits a size advisory for the single JavaScript bundle.
- Advanced Phase 4 catalyst simulation, Guided Journey, and audio are outside this release.
