# Simulation Constitution

This document constrains every future implementation decision.

1. **Unity is fundamental.** Separation is modeled as an experiential condition, not as an ultimate metaphysical substance.
2. **Free will may not be silently overridden by simulation mechanics.** Higher-level systems may present conditions, resources, or probabilities, but choices remain with the entity where the source says they do.
3. **Catalyst does not force polarity.** Similar catalyst must be able to produce different responses and developmental directions.
4. **Service to Others and Service to Self are orientations, not a cartoon morality meter.** UI language should avoid arbitrary “good/evil” scoring.
5. **Harvest is represented as vibrational compatibility/resonance rather than divine judgment.**
6. **Density does not equal physical altitude.** Higher density is not rendered simply as “up.” Spatial arrangements are explanatory metaphors.
7. **Time/space is not another physical room.** Any geometry representing it is explicitly a visualization abstraction.
8. **A social memory complex does not erase individuality by default.** Shared memory and coherence increase without turning the model into a hive-mind caricature.
9. **The Higher Self is not a commanding deity.** It functions as a resource for healing and programming while preserving free choice.
10. **Source-backed claims, inferences, and simulation abstractions are never merged into one epistemic category.**
11. **A visual effect must communicate an existential relationship.** Decoration alone is not a sufficient reason to add complexity.
12. **No invented numeric mechanic may be presented as if Ra supplied the number.** Source-backed thresholds are stored separately from simulator-only weights and deltas.
13. **The simulator models The Ra Contact ontology; it does not present that ontology as established physical science.**

Any future feature that conflicts with this constitution must either be redesigned or explicitly documented as a conscious exception.
