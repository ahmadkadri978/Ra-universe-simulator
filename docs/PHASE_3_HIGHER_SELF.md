# Phase 3 — Higher Self, Time/Space, and possibilities

## Interaction model

```text
PLANNING → ENTRY → INCARNATE → DEATH_TRANSITION → REVIEW → HEALING
    ↑                                                          │
    └──────── archive this life; prepare the next ──────────────┘
```

Each stage is user-initiated. Inspecting Time/Space does not kill the entity or advance the lifecycle. The sequence is a teaching abstraction, not a fixed source timetable.

Programming exposes lesson focus, predisposition, limitation, relationship, catalyst opportunity, environment, and priority. Lesson, relationship, and catalyst opportunity inform example events. Remaining presets are recorded context and visual configuration; they do not calculate future responses.

## One identity, different information

| Lens | Visible information | Choice authority |
| --- | --- | --- |
| Incarnate self | Last three events while incarnate; local possibility field | Explicit response to pending catalyst |
| Higher Self | Current life record, patterns, optional guidance and programming | None |
| Totality | Current and archived records, plus graph parent–child connections | None |

Changing a lens never changes identity, events, or outcomes. Higher Self is a layered information atlas rather than an enlarged entity body.

Space/Time arranges experience chronologically. Time/Space reshapes the same nodes into a relational lattice, linking shared lessons and relationships. Layouts, ribbons, loops, shader fields, fog, animation, and camera travel are SIMULATION_ABSTRACTION.

## Reusable possibility engine

Each node stores id, label, sourceClassification, visualWeight, status, relatedLessons, relatedCatalyst, energyCenterTendencies, childPossibilities, responseAffinity, and parentId.

An explicit response strengthens a related root, weakens others, may close the current invitation to defer, and opens a child possibility. Closed nodes remain inspectable. Deferral remains possible at later decisions. Weights are independent emphasis values, not a normalized distribution.

Each catalyst starts a fresh local graph. Prior choices persist in life history; prior graphs are not a multiverse archive. Totality's additional links follow actual child IDs.

The engine is deterministic for reproducible tests. No transition predicts or selects a future response.

## Authority boundary

CHOOSE requires all of:

- actor === ENTITY
- perspective === INCARNATE_SELF
- phase === INCARNATE
- a pending catalyst
- a recognized response

Invalid input is rejected before events or branches change. Guidance returns only HigherSelfState. Legacy polarity numbers remain untouched by Phase 3 choices.

## Review and healing

Review groups actual catalyst events by lesson and response. Inspectors expose recorded choice, energy tendency, orientation, relationship, and lesson. Tendencies are illustrative annotations, not spiritual diagnostics.

Every catalyst initially awaits reflection, regardless of response. Integration changes only its review annotation. Entry/death markers and unknown IDs cannot be integrated. Re-entry archives the complete previous program, events, and integration IDs.

Source Inspector links concise paraphrases to the relevant questions. No extended copyrighted passages are included.

## Deliberate limits

Session state is in memory, with no persistence or export/replay UI. Reproducible replay exists at the pure reducer API. Advanced catalyst simulation, two-entity comparison, Guided Journey, and audio are excluded. The model does not claim omniscience, metaphysical healing, or measurable future probabilities.
